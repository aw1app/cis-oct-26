Testing tools

Recommended tools for the MediTrack test strategy, selected for the React frontend, Python/FastAPI services, PostgreSQL database, and GitHub Actions CI/CD pipeline.

Implementation note: Confirm the existing frontend build and test setup before adding packages. Run security scans and performance tests only against approved code, dependencies, and non-production environments.

Test type Tool Reason
Unit pytest for Python; Vitest and React Testing Library for React Fits the backend and frontend stack. Run fast, deterministic tests on every pull request to catch regressions in analytics calculations, validation, time/unit handling, and component states.
API / integration pytest, httpx, and a PostgreSQL service container in GitHub Actions Exercises FastAPI contracts and real PostgreSQL persistence, including patient-data updates, duplicate or reordered events, corrections, and error handling. Run focused tests on pull requests and broader regression on a schedule or before releases.
Security Bandit, pip-audit, npm audit, OWASP ZAP Baseline, and pytest authorization tests Checks Python code and dependency risks, frontend dependencies, and authorized API behavior. Use tests for MediTrack role-based access and patient isolation. Run ZAP against an approved non-production target; manually review important findings and authorization edge cases.
Performance k6 for API/load probes; Playwright for dashboard refresh timing k6 measures throughput, latency percentiles, and sustained synthetic availability. Playwright can measure the interval from an accepted test update to its dashboard display. Use a stable, representative environment because shared CI runner timings can be noisy.
UI / responsive Playwright Automates critical provider workflows across browsers and viewport sizes, including mobile emulation, in GitHub Actions. Supplement emulation with representative real-device checks for touch, orientation, zoom, and mobile browser behavior.
User acceptance Provider-led acceptance checklists tracked in GitHub Issues or Projects; Playwright regression tests Keeps workflow evaluation and sign-off human-led for doctors, nurses, and administrators. GitHub Actions can rerun accepted workflows as regression checks and retain reports as artifacts; automation does not replace provider judgment.

GitHub Actions workflow

Run unit tests and focused API checks on pull requests. Run broader integration, security, and UI suites nightly or before releases. Publish test and coverage reports as workflow artifacts. Run sustained performance and availability checks on a stable test environment; reserve the 30-day availability objective for continuous monitoring outside short-lived CI jobs.

Based on the MediTrack project brief and test strategy Tool versions and target environments should be pinned by the project
